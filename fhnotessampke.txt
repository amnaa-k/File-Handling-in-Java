EXAMPLE OF LOADING DATA FROM A FILE NAMED Example1.csv:

public class ReadExcel {
    public static void main(String[] args) throws IOException {
            BufferedReader br = new BufferedReader(new FileReader("Example1.csv"));
            while ((line = br.readLine()) != null) {
                System.out.println(line);
            }
    }
}

this example of file handling syntax breaks down to the following points:
- BufferedReader is the class used to open the file and start reading
- BufferedReader is declared in an object so that BufferedReader can open the file from "Example1.csv"
- a String variable is declared to store each line read from the file
- br.readLine() != null means br (BufferedReader object) reads String line until line becomes null
 
import java.io.BufferedReader;
import java.io.FileReader;
import java.io.IOException;
